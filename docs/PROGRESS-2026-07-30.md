### 2026-07-30 多模态调研与确认

核验来源包括 MinerU、Docling、Unstructured、Marker、NVIDIA NeMo Retriever，AWS
Bedrock、Azure AI Search、Google Agent Search，以及 ColPali/ColQwen2、VisRAG、DSE、
VDocRAG 等论文和官方仓库。

确认采用：

1. `PDF -> MinerU 强制 OCR -> 内部 Element Schema`，保留 element、page、bbox、父子
   关系、表格 HTML、公式 LaTeX、图片/caption/footnote 和原始资产引用。
2. 结构化、token-aware 的父子分块：正文 child 256-512 tokens、parent section
   1,000-2,000 tokens；表格、代码、公式和图片使用专门边界，overlap 只处理单个超长
   元素。
3. 文本主链使用 BM25 + BGE-M3；页面视觉向量使用独立索引；ColQwen2 只对 top 20-50
   页面做 late-interaction 重排，不把全库 patch 多向量塞入 ES。
4. 返回命中 child、必要 parent、邻接块、页面图和 bbox，保证可定位引用。
5. 先执行 500-2,000 页多模态 pilot 和不少于 120 条分层 qrels；视觉模型必须通过
   本地质量、显存、索引体积和许可证门槛后才能创建生产 alias。

许可证风险：MinerU 3.1 之后是基于 Apache 2.0 的自定义 MinerU Open Source License，
不能按普通 Apache-2.0 处理；Marker 代码和模型权重许可证不同；ColQwen2 checkpoint 与
基础模型条款需要分别锁定和审计。
