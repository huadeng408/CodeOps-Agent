### Acceptance blocker discovered

The first real agent turn is not healthy with the current relay configuration.
With no local settings override, Go defaults `model_fast` to `gpt-4o-mini` and
passes it as `MODEL_FAST` to the auto-started Python orchestrator. The configured
relay rejected that model with HTTP 400, accepting only `deepseek-v4-pro` or
`deepseek-v4-flash`. The CLI preserves the session and prints the error, but a
normal first interaction fails before useful work. This is a reproducible
configuration compatibility defect. Do not claim end-user conversational flow
is verified until the fast-model default is aligned with the configured relay
or safely disabled, with an explicit real-agent regression test.
