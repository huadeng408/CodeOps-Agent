### A.3 缺陷 23：str 传进需要 Path 的 `_instance_workdir`

**VERIFIED**（本轮新发现）

**问题**：runner 调 `setup_workspace(instance, str(workspace))`，`prepare(instance, workspace)` 里的 `workspace` 是字符串。`_instance_workdir` 用 `/` 运算符：`workspace / instance.instance_id` → `TypeError: unsupported operand type(s) for /: 'str' and 'str'`。

**失效路径**：`_setup_workdir`（clone 仓库）在 `/` 之前调用且成功 → clone 正常、agent solve 正常、scorer 正常、artifact 结构完整。只有 `_augment_for_uplift` 没有被调用到 → **定位记录静默消失**。

arm B 第一次用 fix 后的代码跑（e5030846）依然 0 条记录，因为 `prepare` 里的 TypeError 阻止了 `_augment_for_uplift` 执行。`mechanism_report.py` 打出「NO RANKING RECORDED — unexpected in this arm」，把问题逼出来。

**修复**：`eval/benchmarks/swebench.py:1743` → `Path(workspace)` 一字修正。

**证据**：
- `tests/eval/test_localization_reaches_artifacts.py::test_prepare_called_with_str_workspace_still_records_localization`：用 str workspace 调 `_instance_workdir` + `_augment_for_uplift`，断言 localization 进了 metadata。
