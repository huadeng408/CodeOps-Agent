# Triage Labels

| 技能角色 | GitHub 标签 / 本地 Triage 值 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待评估 |
| needs-info | needs-info | 缺少必要信息 |
| ready-for-agent | ready-for-agent | 规格明确，可交给 Agent 执行 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 决定不实施 |

GitHub 使用标签；本地草稿使用 Triage: 字段。
同一任务已发布后，以 GitHub 标签为准。

标签只负责分流，不替代 DESIGNED、IMPLEMENTED、VERIFIED、BLOCKED，
也不产生 HUMAN_REVIEWED 或授予新的执行权限。
