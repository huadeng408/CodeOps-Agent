## V0.1 Quiet Operator CLI 发布候选

### DESIGNED

- Quiet Operator CLI 采用低噪声、可扫描的终端语义层级：bootstrap、工具生命周期、assistant 流、权限、问题、diff、status 和中断均使用结构化输出。
- 权限语义分为 `AskSession` 与 `AlwaysAsk`：前者显示 `[y] Allow session  [n] Deny` 并可持久化到当前会话；后者显示 `[y] Allow once  [n] Deny`，不允许会话级放行。
- 工具活动行只允许非空且精确匹配的 `ToolCallID` 原位替换；空 ID 和并行/乱序事件必须保留为 durable audit log。
- 窄终端以完整 metadata token 为边界布局；`1.4s`、`2.1s`、`tokens 1200 in / 300 out` 不允许字符级拆分。
