## V0.1 Quiet Operator CLI 发布候选

### DESIGNED

### 签名信任根与最后一轮 fail-closed 收紧

- canonical release policy 由代码内 SHA-256 trust root 固定；最终重放防护更新后的 policy hash 为 `68e154d4464cc2e17168463e4f9d153fe4e4b619bdbfbba3fb673ba0ecda77f6`，且 policy sidecar 与代码 trust root 一致；CLI 不能换入自定义 policy 来关闭门禁。
- review identity 只有在 Ed25519 签名覆盖精确 A/B sidecar digest 与派生 identity payload 后才是 `MODEL_IDENTITY_ATTESTED`；sidecar 任一字节变化都会使签名失效。`passes_independent` 必须显式为 `true`，字段缺失同样触发 `MODEL_REVIEW_PASSES_NOT_INDEPENDENT`。
- `--bindings` 现在只能引用 canonical artifact tree。reporter 校验 `run-manifest.json`、`predictions.jsonl`、`scorer/metadata.json`、`checksums.sha256`，要求 artifact `git_sha` 等于当前 HEAD，并验证 checksum 文件的 Ed25519 签名；攻击者同时篡改 artifact 与 checksum 也不能替代签名私钥。
- policy v1 显式保存空的 `attestation_public_key_b64` 与 `artifact_attestation_public_key_b64`，表示当前没有可信生产公钥。没有填测试 key 或假 key；因此真实 E5 继续 fail closed。
