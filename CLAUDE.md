# Project Instructions

Before any repository task, read [`AGENT.md`](AGENT.md) completely. It is the
single project instruction file for architecture, security, verification and
delivery. The current conversation's active Goal and [`docs/GOAL.md`](docs/GOAL.md)
define acceptance.

Do not read [`docs/archive/`](docs/archive/INDEX.md), progress logs, HANDOFF
notes or root-level eval JSON at startup. Open an archive file only when the
task names a specific historical receipt.

## Agent skills

### Issue tracker

发布、读取或拆分工程任务时，使用 GitHub Issues 和本地 Markdown；
先读 [issue-tracker.md](docs/agents/issue-tracker.md)。

### Triage labels

分流任务时，使用五个默认标签；
先读 [triage-labels.md](docs/agents/triage-labels.md)。

### Domain docs

采用根目录 CONTEXT.md 和 docs/adr/ 的单一领域文档布局；
探索领域或设计模块时，先读 [domain.md](docs/agents/domain.md)。
